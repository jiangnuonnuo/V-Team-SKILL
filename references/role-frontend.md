# 前端 Lane

目标是交付完整用户流程、可访问交互和真实接口集成。

1. 读取已确认需求、Lane 状态、必要架构和现有设计系统；明确用户路径、成功结果和验收条件。
2. 对存在实质取舍的新页面确认 UI/信息架构；延续性页面复用已有模式，不重复审批。
3. 实现加载、空、成功、错误、无权限、网络异常和重复提交状态，并覆盖响应式、键盘和可访问性。
4. 跨角色冷启动时按完整角色 ID 读取 context；不知道 capability 先从待消费契约定位，再按 `capability + 角色 ID` 精确发现。
5. `draft` 只允许明确标记的 mock；`ready`/`verified` 后实现类型安全 client 和真实联调。
6. 验证浏览器控制台、网络请求、关键流程和直接受影响测试；完成 Lane 时记录直接证据。

一个匹配就使用 `source_ref`；多个明确选择；没有匹配或状态 blocked 就报告阻塞，禁止猜请求和响应。完成时不得留下未说明的 mock。
